Solicitud de orientación

Si necesitas una rutina que no aparece en el sitio, contacta a la Unidad de Rehabilitación por los canales institucionales definidos por el Hospital Regional de Copiapó.

Nota técnica: GitHub Pages no ejecuta PHP ni Contact Form 7. Para habilitar un formulario real se debe conectar un servicio externo de formularios o una API.

Sitio estático

Sin WordPress, sin base de datos, sin plugins y sin archivos de cPanel.

Unidad de Rehabilitación

Material educativo migrado a versión estática para GitHub Pages. Ante dolor, mareos, fiebre, falta de aire o aumento de síntomas, suspenda el ejercicio y consulte con un profesional de salud.
